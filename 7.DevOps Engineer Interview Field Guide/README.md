# DevOps Engineer Interview Field Guide

A detailed companion to the existing Notes-Devops_For_Lazy_People repository, focused on Linux troubleshooting, Bash and Python automation, Docker, Kubernetes, AWS/EC2/CloudWatch, CI/CD failure diagnosis, high availability, and scenario-based interview practice.

## Contents
- Repeatable incident-response method and operational safety
- Linux commands for CPU, memory, disk, processes, services, logs, and networks
- Ready-to-run Bash scripts for host health, disk thresholds, service status, and log filtering
- Python scripts for service checks, log analysis, host snapshots, HTTP health checks, and large-file detection
- Docker diagnostics and common failure patterns
- Kubernetes triage for Pending, CrashLoopBackOff, ImagePullBackOff, OOMKilled, no endpoints, and failed rollouts
- AWS identity, EC2 reachability, CloudWatch CPU metrics, and IAM AccessDenied workflows
- CI/CD troubleshooting and deployment verification
- High-availability / latency scenarios
- 16 mock interview scenarios, answer framework, command index, and official documentation links
